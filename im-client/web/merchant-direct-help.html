直连 HTTP 分发使用教程（商户自带文件服务器）

游戏文件不上传平台 · 玩家客户端直连你的服务器下载 · 平台自动逐文件校验完整性 ｜ 适合已有 OSS / CDN / 自建网站服务器的商户

一、直连模式是什么

默认模式下，游戏文件需要上传到平台服务器，由平台分发给玩家。直连模式下，游戏文件保存在你自己的服务器上： 你只需在平台登记一份「文件清单」（文件名 / 大小 / SHA256 指纹），玩家客户端会直接从你的服务器下载每个文件， 并自动逐文件校验指纹——文件被篡改或损坏都会被拒绝安装，玩家拿到的永远和登记时一致。

适合谁：已经有稳定 HTTP 文件服务器（自建 nginx、阿里云 OSS、腾讯 COS、七牛、CDN 等）的商户。 优势：大文件不走平台带宽、更新发布即时、你的服务器上文件自主可控。没有服务器或服务器不稳定请继续使用「平台服务器分发」。

二、你的服务器需要满足

要求说明
HTTPS必须 https://（防传输篡改）；OSS/CDN 开箱即支持，自建服务器请配置证书
支持 Range 请求玩家断点续传必需；nginx 默认支持，主流对象存储原生支持
目录结构与清单一致文件相对路径必须与登记清单完全一致（见下方第 3 步示例）
稳定在线你的服务器宕机 = 玩家暂时无法下载（客户端会提示「来源服务器」错误）；建议使用 OSS/CDN 而非家用宽带

三、操作步骤

1

设置下载方式

商户后台 → 我的应用 → 新增/编辑游戏 → 「下载方式」选择 直连 HTTP（文件在商户自己的服务器） → 填写文件服务器根地址（如 https://cdn.example.com/mygame/）→ 保存。 游戏将进入待审核，审核通过后生效。

根地址禁止包含 ..、问号 ?、井号 #；必须以 https:// 开头。
2

把游戏文件放到你的服务器

按与本地目录完全一致的相对结构放置。例如本地目录是 D:\mygame\，根地址是 https://cdn.example.com/mygame/：

本地 D:\mygame\bin\game.exe    →  https://cdn.example.com/mygame/bin/game.exe
本地 D:\mygame\data\pack.pak  →  https://cdn.example.com/mygame/data/pack.pak
本地 D:\mygame\readme.txt     →  https://cdn.example.com/mygame/readme.txt

中文文件名/空格无需处理，平台会自动编码。

3

登记版本清单（文件不上传平台）

我的应用 → 游戏卡片「版本管理」→ 填写版本号 → 保持「散文件目录」方式 → 点「选择目录」选中本地完整游戏目录 → 点「开始登记清单（文件不上传）」。

页面会在本地逐文件计算 SHA256 指纹（大目录需要几分钟，请勿关闭页面）， 完成后仅登记清单——游戏文件本体不会经过平台。

限制：单个版本文件清单条数上限由平台管理员配置（默认 5000 项）；单文件上限 50GB；0 字节的空文件会自动跳过。
4

等待审核 → 玩家下载

审核通过后玩家即可安装：PC 客户端直接从你的服务器逐文件下载，每个文件自动校验 SHA256， 全部通过才落盘安装。玩家端会显示「来源：商户服务器」。

四、版本更新（补丁）怎么做

直连模式没有单独的"补丁包"操作，更新流程非常简单：

  1. 在本地对完整游戏目录做变更（新增 / 修改 / 删除文件）；
  2. 把变更后的文件同步替换到你服务器的对应位置；
  3. 商户后台「版本管理」→ 填写新版本号 → 重新选择目录 → 「开始登记清单」；
  4. 玩家端自动检测新版本，只下载有变化的文件（未变化的文件本地直接复用，不重复下载）——效果等同增量补丁。

五、常见问题

现象原因 / 处理
登记时提示"需安全上下文"商户后台须用 https 打开或使用 PC 客户端内置窗口（SHA256 计算的浏览器安全要求）
玩家报「清单缺少直连地址」游戏选了直连但根地址为空——重新编辑游戏补填地址
玩家报「必须为 https」根地址填了 http://——改用 https，或联系平台管理员（内网部署可放开）
玩家报「服务端返回 404」服务器上文件缺失，或目录结构与登记清单不一致——按第 2 步示例核对
玩家报校验失败重试后仍失败服务器上的文件与登记清单不一致（替换了文件但没登记新版本）——重新登记新版本清单
玩家报「来源服务器：网络错误」你的服务器宕机/不可达——检查服务器与防火墙（放行 80/443）
想换回平台分发编辑游戏 → 下载方式改回「平台服务器分发」→ 走正常文件上传（回待审核）

六、平台如何保障安全

你服务器上的文件无法被伪造：文件清单（含每个文件的 SHA256 指纹）由平台持有并下发给玩家， 服务器上的任何文件一旦被篡改，玩家客户端校验失败即拒绝安装。平台不存储、不代理你的游戏文件， 也不会向你的服务器泄露玩家账号信息（直连下载不携带平台参数）。但请注意： 文件内容的合规责任由商户承担——直连模式的文件不经过平台病毒扫描，请自行确保发布内容安全合规， 平台审核员会对直连游戏重点核验来源。
