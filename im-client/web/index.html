      MCP Servers 管理
      管理您已添加的 MCP 服务器，可启用、配置或添加新的工具能力（配置本机 stdio 子进程，凭据仅保存在本机）。

      插件市场

      发现并安装 MCP 插件，拓展 AI 助手的工具能力。点击「安装」自动写入本机 MCP 配置并连接；Python 系插件（uvx）会自动安装运行环境。

      工具链

      安装编译工具链，为 AI 助手提供 C/C++ 编译能力。点击「安装」自动下载、校验并解压；安装后 Agent 任务可直接调用编译命令（系统已装 MSVC/gcc 时优先使用系统编译器，本工具链为兜底）。
