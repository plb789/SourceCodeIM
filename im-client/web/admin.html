Git 助手提示词

源代码管理「AI 生成提交信息」与「AI 审查报告」的系统提示词。保存后下一次生成即按新提示词执行（热更新，无需重启服务端），持久化保存重启不丢；清空输入框并保存即恢复内置默认。

MCP 服务器

MCP（Model Context Protocol）服务器由服务端统一建连与调用：stdio 在服务端本机拉起子进程，sse/http 直连远程端点。已连接服务器的启用工具自动注入 AI 智能体（默认逐次人工确认，可开启免审批）。配置保存即热生效，无需重启。

MCP 插件库

插件清单由本页统一维护，PC 端用户在设置 → 插件市场一键安装（自动写入本机 MCP 配置并建连）。环境变量模板中的占位值（密码/令牌/目录）会标记"需配置"，用户安装时补填。删除插件不影响用户已安装的本机配置。

工具链市场

工具链清单由本页统一维护，PC 端用户在设置 → 工具链一键下载安装（SHA256 校验后解压到 ~/.im-mcp/<安装目录>）。区别于 MCP 插件：工具链非长驻进程，安装即下载解压即可用；Agent 任务可直接调用编译命令。删除条目不影响用户本机已安装的目录。

导入 mcp.json

粘贴 TRAE / Claude / Cursor 的 mcp.json 内容（{"mcpServers": {...}} 或直接的服务器对象），将逐个导入为 MCP 服务器。
