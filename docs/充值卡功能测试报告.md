## 9. 测试过程中发现并修复的问题（均为测试基建，产品代码无恙）

| # | 问题 | 修复 |
|---|------|------|
| 1 | `User.Points` 零值被 GORM 按 `default:100` 跳过，测试用户实际建出 100 分 | 测试建用户后显式归零 |
| 2 | 直调生成接口 `created_by` 为空串，清理条件匹配不到导致卡残留 | 清理改按测试批次精确删除 + 空串兜底 |
| 3 | 频控表进程内跨用例累积污染 | 每用例 setup 重置 |
| 4 | E2E 核销请求漏 `username` 参数 → 守卫 401 | 补参数（该 401 恰好证明守卫生效） |
| 5 | 清理语句对 `im_recharge_card` 误用不存在的列 `username`（实为 `used_by`）报 Error 1054 | 改为 `used_by LIKE 'cardtest_%'` |
| 6 | 并发用例全表 `First(&card)` 取到库中本地实测遗留的历史卡（卡密对不上 → 8 并发全失败），仅在有遗留数据时偶发 | 改按本测试批次 `batch_no` 取卡（并发用例与导出用例两处） |
