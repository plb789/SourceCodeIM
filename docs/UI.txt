开发后台可视化拖拽布局编辑器：

1. 支持PC端、移动端双端独立 UI 布局编辑**，两端布局配置相互隔离；
2. 后台管理页提供拖拽画布，可拖拽组件（按钮、文本、容器等），支持调整组件位置、大小、层级、基础属性；
3. 编辑完成后保存布局配置 JSON，**无需重新发布、无需打包**，热更新线上前端页面；
4. 前端业务页面读取后端存储的布局 JSON，动态渲染页面 UI，实现按钮等组件位置、样式的自定义生效；
5. 支持预览 PC / 手机端效果，编辑可回滚，配置持久化存储数据库。

关键避坑点（Go + 原生 JS 特有）

1. ❌ 拖拽过程频繁调用 Go 后端保存数据
✅ 拖拽只改内存，保存草稿 / 发布才请求接口
2. ❌ 草稿与线上共用同一份数据库记录，编辑直接污染线上
✅ 草稿表和正式表物理隔离，发布才复制数据
3. ❌ Go 不做二次校验，直接原样存储前端 JSON
✅ Go 后端强制校验、过滤危险样式、限制报文大小
4. ❌ 前端业务页面每次渲染都请求数据库
✅ Go 层加缓存，热更新靠主动失效缓存 key 实现
