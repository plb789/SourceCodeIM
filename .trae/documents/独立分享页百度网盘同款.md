# 网盘分享独立页面（百度网盘同款）

## Context

当前 `/s/<code>` 分享链接回主应用 index.html，访客必须登录后才能在弹窗中查看/保存分享文件。需求：打开分享链接进入**独立轻量页面**（不进主应用），**免登录**即可查看文件信息并直接下载；"保存到我的网盘"需要登录（页面内自绘登录面板，登录成功自动执行保存）。百度网盘同款体验。

可行性结论（已核实）：后端本来就支持——
- `GET /api/drive/share/info` 免登录（凭 code+extract，`drive_share.go` L334）
- `GET /api/drive/share/download` 免登录，`serveDriveFile` 两种后端均触发浏览器下载（本地流式带 `Content-Disposition: attachment` L497；MinIO 302 预签名带对象级 disposition L420）
- `POST /api/drive/share/save` 需 `driveCheckUser`（WS 在线水位，`drive.go` L43-54）→ 独立页保存前须建立 WS 登录
- **无需新增任何服务端 API**，全部复用现有三个接口

### 2. 新建 `im-client/web/share.html`
百度网盘分享页同款布局（全部自绘组件，禁系统弹窗）：
- 顶栏：左 logo「网盘」，右用户区（未登录→"登录"按钮；已登录→用户名+退出）
- 中央文件卡片：大文件图标（按 is_dir/扩展名，复用 drive.js 的 ICONS 思路）、文件名、大小、"分享人：xxx · 永久有效/有效期至…"
- 提取码行（`need_extract=true` 时显示）：输入框（自动转大写，maxlength=4）+ 提取按钮，Enter 支持
- 按钮行：下载（文件夹隐藏）、保存到我的网盘
- 登录浮层（`.sp-login-mask`，自绘）：账号/密码/登录按钮/错误提示行
- 失效态：大图标 + 服务端返回的失效文案（已取消/已过期/文件已删除/不存在）
- 自绘 toast + 自绘滚动条样式（沿用项目规范）
- **资源全部根绝对路径** `/css/style.css` `/js/socket.js` 等（深层路径 /s/xxx 下相对路径会 404，历史坑）
- head 内联主题引导脚本：读 `localStorage['im_theme']`（'light'/'dark'/'system'）→ 设 `data-theme`（仿 index.html 首绘引导，防主题闪烁）

### 3. 新建 `im-client/web/css/share.css`
页面专属样式（约 300-400 行）。主题变量直接引用 style.css 既有变量（`--primary/--panel-bg/--text/--border` 等，light/dark/system 三态自动跟随，零重复定义）。先例：register.html（引 style.css + 内联补充样式，久经上线）。

### 4. 新建 `im-client/web/js/share-page.js`
IIFE 状态机：`解析code → info → (need_extract? 输提取码 : 失效态/就绪) → 下载/保存/登录`
- `parseCode()`：pathname 正则 `/^\/s\/([A-Za-z0-9]{6,40})$/`（同 chat.js L21658）
- `fetchInfo()`：调 info 接口；`need_extract=true` 显提取码行；其余 error → 失效态渲染服务端文案
- `download()`：`location.href = '/api/drive/share/download?code=&extract='`
- `save()`：POST save `{username, code, extract, parent_id:0}`
- 登录凭据：读/写 `localStorage['im_auth']`（base64+encodeURIComponent JSON `{u,p}`，同 chat.js L338-346 逻辑独立实现，同域共享）
- **依赖 socket.js（已核实可独立加载）**：IIFE 自含无 chat.js/DOM 依赖，`window.desktop/__webCallBridge/P2PFile` 引用均有守卫；`IMSocket.on(MSG.LOGIN_RESP)` 收帧判断 `result==='ok'`（JSON 格式，兼容旧 'ok'）；失败监听 `MSG.ERROR`(9) + `window.addEventListener('im_connect_failed')`

### 5. 保存时序
- 页面加载：有 `im_auth` → 立即 `IMSocket.connect`（右上角显用户名，百度同款）；连接失败/登录被拒（密码已改）→ 清 im_auth 回未登录态
- 无 im_auth 点保存 → 弹登录面板 → connect → LOGIN_RESP 成功 → 存 im_auth + 顶栏更新 + **自动补发 save**
- 已登录点保存 → 直接 POST save（WS 已在线通过 driveCheckUser）

### 6. 主应用回归面
- chat.js `dsConsumePendingShareLink`（L21657-21665）变死代码：函数头加注释标注废弃保留（规则：注释而非删除）；`/s/` 不再回 index.html 后此逻辑不再触达
- 站内 92 卡片气泡点击弹窗（`IMDrive.showShareCard`）路径**保留不变**（站内登录用户仍走主应用弹窗）
- 分享管理面板/复制链接/创建分享全部不变，仅链接落地页更换
