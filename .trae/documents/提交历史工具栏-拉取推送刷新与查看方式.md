# 提交历史工具栏（TRAE CN 同款）：拉取/推送/刷新/⋯查看方式

## Context

用户希望把 TRAE CN（VS Code 源代码管理图形视图）提交历史上方的工具栏能力加进 IM 客户端的「提交历史」分区头部：拉取、推送、刷新图标按钮，以及「···」菜单里的**查看方式**（以列表形式查看 / 以树形式查看）。

现状：
- 拉取/推送/刷新逻辑已存在（挂在面板最顶部头部），动作归口 `wsPanelGitAct` / `wsPanelGitRefresh`，直接复用
- 提交展开后的文件列表只有**平铺**渲染（语言徽标+文件名+目录后缀+状态标），无树形嵌套
- 「代码提交」不进工具栏——提交输入框本就在提交历史上方，与 TRAE CN 一致

web 文件由服务端直接托管（no-cache），改完刷新即生效，无需打包 PC 端。
